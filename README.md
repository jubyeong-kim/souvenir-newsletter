# 오늘의 기념품

매일 아침 **대륙이 하나씩 돌아가며**, 그날 선정된 국가에서 지금 화제인 기념품을 추려
디스코드로 발행하는 뉴스레터 에이전트입니다.

여행을 준비하는 독자가 "이번 여행에 뭘 사올까"를 정할 수 있도록, 기사 본문을 실제로 읽고
요약한 뒤 **원문에 없는 내용이 섞이지 않았는지 검수한 것만** 내보냅니다.

- 발행 예시와 설계 판단은 **[REPORT.md](REPORT.md)** 에 있습니다.
- 날짜만으로 대륙·국가가 결정되므로 같은 날 실행하면 항상 같은 국가가 나옵니다.

## 파이프라인

```
START → collect → select ─(기사 수만큼 팬아웃)→ report → verify → publish → END
        수집       선별                          취재      검수      발행
```

| 단계 | 하는 일 |
|---|---|
| **수집** | 국가별 쿼리형 소스(Tavily·YouTube)와 고정 RSS에서 후보를 모읍니다 |
| **선별** | 예선(묶음)→본선 2단계로 추리고, 한 소스가 자리를 독차지하지 못하게 상한을 겁니다 |
| **취재** | 본문을 확보해 헤드라인·요약·여행자 관점 인사이트를 씁니다 |
| **검수** | 품목명 원문 대조 → 숫자 대조 → LLM 근거·국가 판정. 비용 0인 검사부터 돌립니다 |
| **발행** | 검수를 통과한 것만 디스코드 임베드로 보냅니다 |

검수에서 떨어지면 그 건은 버리고, 목표 건수에 미달해도 **기준을 낮춰 채우지 않습니다.**
한 건도 남지 않은 날에도 안내 임베드 한 장은 보냅니다 — 아무것도 안 보내면
파이프라인이 죽은 것과 구분이 되지 않기 때문입니다.

## 폴더 구조

```
souvenir-newsletter/
├── graph.py                     파이프라인 전체. 여기에는 '구조'만 둡니다
├── run.py                       실행 진입점
├── audience.yaml                '내용'은 전부 여기 — 독자 정의, 선별 기준,
│                                대륙·국가 로테이션, 소스 목록, 임베드 색상
├── requirements.txt
├── REPORT.md                    프로젝트 보고서 (소스 채택표·선별 로직·실행 기록)
├── docs/
│   └── discord.jpg              발행 화면 캡처
├── store/
│   ├── metrics.jsonl            실행마다 한 줄. 수집→선별→취재→발행 깔때기
│   └── seen.json                이미 발행한 URL. 같은 것을 다시 보내지 않습니다
└── .github/workflows/daily.yml  매일 09:00 KST 자동 실행
```

**다른 분야로 옮기려면 `audience.yaml` 만 고칩니다.** 소스 종류(`tavily`/`youtube`/`rss`)와
국가 로테이션, 선별 기준이 전부 설정 파일에 있어서 파이썬을 열 일이 없습니다.

## 실행

```bash
pip install -r requirements.txt
```

`.env` 파일에 키를 넣습니다. 이 파일은 커밋되지 않습니다.

```
OPENAI_API_KEY=
DISCORD_WEBHOOK_URL=
TAVILY_API_KEY=
YOUTUBE_API_KEY=
```

```bash
python run.py
```

`DRY_RUN` 은 **기본값이 보내지 않음(`1`)** 입니다. 실제로 발행하려면 `DRY_RUN=0` 을 줍니다.
기본값을 이렇게 둔 이유는, 설정을 빠뜨린 채 돌렸을 때 조용히 발행되는 쪽보다
아무 일도 일어나지 않는 쪽이 안전하기 때문입니다.

## 수집 소스

| 소스 | 종류 | 왜 넣었나 |
|---|---|---|
| Tavily (한국어·영어) | 쿼리형 API | 국가별로 질의할 수 있고 본문까지 함께 받습니다 |
| YouTube Data API v3 | 쿼리형 API | 기념품 하울 영상이 유행의 1차 소스입니다 |
| TimeOut | RSS | 도시 단위 쇼핑·시장 기사 |
| Atlas Obscura | RSS | 지역 특산·희귀품 |

검토했다가 **탈락시킨 소스 6개와 그 수치적 근거**는 [REPORT.md](REPORT.md#2-소스-채택표) 에 있습니다.
